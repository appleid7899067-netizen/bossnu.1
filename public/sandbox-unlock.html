🧪 Sandbox Unlock

ห้องทดลองสำหรับรัน HTML, CSS และ JavaScript — เปิดความสามารถที่จำเป็น แต่คงการแยก origin เพื่อปกป้องข้อมูลหลัก

โค้ด
ผลลัพธ์isolated origin
ความปลอดภัย: iframe นี้ ไม่มี allow-same-origin และไม่มีสิทธิ์เข้าถึง cookies, localStorage, DOM ของหน้าหลัก หรือการนำทางหน้าหลักโดยตรง เปิดใช้เฉพาะความสามารถสำหรับการทดลองที่จำเป็น
