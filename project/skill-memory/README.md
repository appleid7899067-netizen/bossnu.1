# Sali Skill Memory

The Auto-Skill Engine records reusable lessons from verified work.

Lifecycle:
1. extract a lesson from real evidence
2. deduplicate/merge by scenario
3. create a candidate
4. verify it in Sandbox
5. promote only after verification
6. update usage statistics
7. archive only Sali-generated skills that are no longer used

Source of truth for verified skills remains `project/skills/verified/`.
